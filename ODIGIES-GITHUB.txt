ΤΙ ΠΕΡΙΕΧΕΙ ΑΥΤΟΝ ΤΟΝ ΦΑΚΕΛΟ
----------------------------
Ο φάκελος αυτός είναι ΟΛΗ η ιστοσελίδα σας, έτοιμη για το GitHub Pages.
Το αρχείο «index.html» που βλέπετε στην κορυφή είναι η ΑΡΧΙΚΗ ΣΕΛΙΔΑ —
αυτό διαβάζει πρώτο το GitHub. ΜΗΝ ανεβάσετε μόνο αυτό το αρχείο:
ανεβάστε ΟΛΑ τα αρχεία και τους φακέλους ακριβώς όπως είναι (ίσως
περισσότερα από 1.000 αρχεία — είναι φυσιολογικό, περιλαμβάνουν όλες
τις σελίδες, τα 3D γραφικά, το e-shop και τις εικόνες).

Σημαντικό: το κρυφό αρχείο «.nojekyll» είναι απαραίτητο — χωρίς αυτό
δεν φαίνονται τα στυλ και τα γραφικά. Ελέγξτε ότι ανέβηκε (βλ. Βήμα 3).


ΒΗΜΑ 1 — ΛΟΓΑΡΙΑΣΜΟΣ GITHUB
---------------------------
1. Πηγαίνετε στο https://github.com και πιέστε «Sign up» (εγγραφή) —
   ή κάντε login αν έχετε ήδη λογαριασμό.
2. Κρατήστε σημειωμένο το «όνομα χρήστη» (username) σας — θα το
   χρειαστείτε. Π.χ. αν το username σας είναι «giorgos123».


ΒΗΜΑ 2 — ΔΗΜΙΟΥΡΓΙΑ REPOSITORY (επιλέξτε ΕΝΑΝ τρόπο)
----------------------------------------------------
ΤΡΟΠΟΣ Α (ΠΡΟΤΕΙΝΕΤΑΙ — δουλεύει άμεσα ΚΑΙ αργότερα με το
www.prostegi.gr, χωρίς ποτέ αλλαγές αρχείων):

  Δημιουργήστε repository με όνομα ΑΚΡΙΒΩΣ:  to-onoma-sas.github.io
  (π.χ. «giorgos123.github.io»)

  → Η ιστοσελίδα θα εμφανιστεί στο:  https://to-onoma-sas.github.io
  → Αργότερα, το www.prostegi.gr δουλεύει με τα ΙΔΙΑ αρχεία, χωρίς καμία
    αλλαγή.

ΤΡΟΠΟΣ Β (αν θέλετε το repo να λέγεται «prostegi»):

  Δημιουργήστε repository με όνομα ΑΚΡΙΒΩΣ:  prostegi
  → Η ιστοσελίδα θα εμφανιστεί στο:  https://to-onoma-sas.github.io/prostegi
  ΠΡΟΣΟΧΗ: αυτός ο φάκελος έχει φτιαχτεί ειδικά για το όνομα «prostegi».
  Αν δώσετε άλλο όνομα στο repo, δεν θα φαίνονται σωστά τα στυλ.
  Και ΠΡΟΣΟΧΗ 2: αν αργότερα συνδέσετε το www.prostegi.gr (Βήμα 5), θα
  πρέπει να αντικαταστήσετε τα αρχεία του repo με το ΠΕΡΙΕΧΟΜΕΝΟ ΤΟΥ
  ΑΛΛΟΥ ZIP (αυτό που γράφει «για www.prostegi.gr / custom domain»).

  Πώς δημιουργείτε repo: πιέστε το «+» πάνω δεξιά → «New repository» →
  όνομα → Public → «Create repository».


ΒΗΜΑ 3 — ΑΝΕΒΑΣΜΑ ΤΩΝ ΑΡΧΕΙΩΝ
-----------------------------
1. Μέσα στο νέο repository πιέστε το link «uploading an existing file»
   (ή Add file → Upload files).
2. Ανοίξτε τον φάκελο της ιστοσελίδας στον υπολογιστή σας, επιλέξτε ΟΛΑ
   τα αρχεία/φακέλους ΜΕΣΑ του (Ctrl+A / Cmd+A) και σύρετέ τα στη σελίδα
   του GitHub. Περιμένετε να ολοκληρωθεί το ανέβασμα.
3. Στο πεδίο κάτω γράψτε π.χ. «Ανάρτηση ιστοσελίδας» και πιέστε
   «Commit changes».
4. ΕΛΕΓΞΤΕ: στη λίστα των αρχείων πρέπει να βλέπετε το «index.html» ΚΑΙ
   το «.nojekyll». Αν ΔΕΝ βλέπετε το «.nojekyll»:
   - Πιέστε «Add file» → «Create new file»
   - Στο όνομα γράψτε:  .nojekyll   (αφήστε το περιεχόμενο κενό)
   - Πιέστε «Commit changes».
   (Ο φάκελος _next δεν χρειάζεται καμία αλλαγή.)


ΒΗΜΑ 4 — ΕΝΕΡΓΟΠΟΙΗΣΗ GITHUB PAGES
----------------------------------
1. Στο repository: Settings (ρυθμίσεις, πάνω) → αριστερά «Pages».
2. Στο «Build and deployment» → Source: «Deploy from a branch».
3. Branch: επιλέξτε «main» και φάκελο «/(root)» → «Save».
4. Περιμένετε 1–3 λεπτά, κάντε ανανέωση της σελίδας. Θα εμφανιστεί
   πράσινο μήνυμα «Your site is live at …» με τον σύνδεσμο της σελίδας σας.


ΒΗΜΑ 5 (ΠΡΟΑΙΡΕΤΙΚΟ, ΟΤΑΝ ΘΕΛΕΤΕ) — ΣΥΝΔΕΣΗ www.prostegi.gr
-----------------------------------------------------------
Για να βάλετε το επίσημο domain σας πάνω στη νέα σελίδα:

1. Στον πάροχο όπου έχετε το domain prostegi.gr (όπου πληρώνετε την
   ανανέωσή του), βρείτε τη διαχείριση DNS και προσθέστε:
      Τύπος     Όνομα     Τιμή
      CNAME     www       to-onoma-sas.github.io
      A         @         185.199.108.153
      A         @         185.199.109.153
      A         @         185.199.110.153
      A         @         185.199.111.153
   (αντί για «to-onoma-sas» βάλτε το δικό σας username· αν υπάρχει ήδη
   άλλη εγγραφή www ή A, αλλάξτε την — μην σβήσετε τα MX του email.)
2. Στο GitHub: Settings → Pages → «Custom domain» → γράψτε
   www.prostegi.gr → Save.
3. Περιμένετε μέχρι το DNS να «πιάσει» (συνήθως 30 λεπτά – 2 ώρες),
   μετά ενεργοποιήστε «Enforce HTTPS» στο ίδιο σημείο.
4. Αν είχατε ακολουθήσει τον ΤΡΟΠΟ Β (repo «prostegi»), πρώτα
   αντικαταστήστε τα αρχεία του repo με το περιεχόμενο του ZIP που
   γράφει «για www.prostegi.gr», μετά κάντε το βήμα 2.
5. Τέλος, στο Google Search Console υποβάλετε το sitemap:
   https://www.prostegi.gr/sitemap.xml


ΒΗΜΑ 6 — ΟΙ ΦΟΡΜΕΣ (ΠΟΛΥ ΣΗΜΑΝΤΙΚΟ)
-----------------------------------
Όλες οι φόρμες της σελίδας (δωρεάν μελέτη, παραγγελίες e-shop, φόρμες
πακέτων 5–20 kW) αποστέλλουν ΑΥΤΟΜΑΤΑ email στο info@prostegi.gr —
δεν χρειάζεστε server ούτε πληρωμή.

ΜΙΑ ΕΝΕΡΓΟΠΟΙΗΣΗ ΧΡΕΙΑΖΕΤΑΙ: την ΠΡΩΤΗ φορά που κάποιος θα στείλει
φόρμα, θα έρθει στο info@prostegi.gr email από τη υπηρεσία FormSubmit
με κουμπί ενεργοποίησης (activation). Πατήστε το ΜΙΑ φορά — από τότε
όλα τα αιτήματα φτάνουν αυτόματα στο email σας, με ωραία μορφή πίνακα.

Δοκιμάστε τη φόρμα μόνοι σας την 1η μέρα (π.χ. από τη σελίδα
«Επικοινωνία») για να ολοκληρώσετε την ενεργοποίηση έγκαιρα — μην
περιμένετε τον πρώτο πελάτη.


ΣΥΧΝΕΣ ΕΡΩΤΗΣΕΙΣ
----------------
• «Ανέβηκε αλλά δεν φαίνονται χρώματα/εικόνες, μόνο κείμενο;»
  → Λείπει το .nojekyll (Βήμα 3.4) ή ανεβάσατε το λάθος ZIP για το όνομα
    του repo (βλ. Βήμα 2).
• «Μπορώ να ανεβάσω μόνο το index.html;»
  → Όχι. Το index.html είναι η αρχική σελίδα, αλλά χρειάζονται ΟΛΑ τα
    αρχεία για να δουλεύουν οι σελίδες, τα 3D γραφικά και το e-shop.
• «Πώς ενημερώνω τη σελίδα αργότερα;»
  → Ανεβάζετε ξανά τα νέα αρχεία στο ίδιο repo (Add file → Upload files)
    και το GitHub το ανανεώνει μόνο του σε 1–2 λεπτά.
• «Το καλάθι και οι παραγγελίες δουλεύουν;»
  → Ναι: το καλάθι δουλεύει στον browser του πελάτη και η παραγγελία
    φτάνει στο email σας (Βήμα 6) — τηλεφωνική επιβεβαίωση, όπως ακριβώς
    θέλατε, χωρίς online πληρωμή.
• «Είναι δωρεάν το GitHub Pages;»
  → Ναι, για δημόσιο (public) repository είναι εντελώς δωρεάν, χωρίς
    διαφημίσεις.
